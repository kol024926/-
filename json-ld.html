JSON-LD

Формат структурированных данных в виде JSON.

Структура JSON-LD

JSON-LD размещается в элементе <script type="application/ld+json">. Такой блок описывает данные отдельно от визуального HTML-кода.

{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Пример статьи",
  "author": {"@type": "Person", "name": "Анна"}
}

Частые поля

Основные элементы JSON-LD
ПолеНазначение
@contextУказывает словарь, например Schema.org.
@typeОпределяет тип сущности.
name / headlineПередают название или заголовок.
authorСвязывает материал с автором.
